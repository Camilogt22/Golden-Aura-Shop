# Golden Aura

Golden Aura es un e-commerce frontend de perfumes enfocado principalmente en fragancias árabes.

El proyecto fue desarrollado como parte de mi proceso de aprendizaje en desarrollo web, aplicando HTML, CSS, Bootstrap y JavaScript Vanilla.

## Descripción

Golden Aura permite explorar diferentes perfumes, buscar y filtrar productos, agregarlos a un carrito de compras y completar un flujo de checkout simulado.

El proyecto está enfocado en practicar lógica de programación, manipulación del DOM, eventos, arrays, objetos, almacenamiento local y consumo de APIs.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript Vanilla
- LocalStorage
- API REST de perfumes
- Git
- GitHub

## Funcionalidades

- Página de inicio responsive.
- Productos destacados.
- Catálogo completo de perfumes.
- Búsqueda de productos.
- Filtro por categoría.
- Filtro por aroma.
- Filtro por disponibilidad.
- Carrito de compras.
- Agregar productos al carrito.
- Aumentar y disminuir cantidades.
- Control de stock.
- Eliminar productos.
- Vaciar carrito.
- Cálculo de subtotales.
- Cálculo del total de compra.
- Persistencia del carrito con LocalStorage.
- Checkout simulado.
- Validación de formulario.
- Consumo de una API REST de perfumes.
- Diseño responsive con Bootstrap.
